# Archer equipment art

- `archer_equipment.blend`: editable master authored through Blender MCP.
- `preview/grapple_hook.png`: original Apex anchor hook studio render.
- `preview/retriever_original.png`: recovered original MOTD world model.
- `preview/cable_native_scale.png`: hook and physical cable at game scale.
- `preview/cable_phases.mp4`: appearance, pull and disappearance art reference.
- `preview/cable_contact.png`: frames 1, 8, 36 and 52 in reading order.
- `preview/bo2_throw.png` / `bo2_flourish.png`: recovered first-person motion.
- `preview/retriever_ember_flourish.png`: native-material translation preview.
- `preview/grapple_first_person.png`: fitted wrist housing and arm pose.
- `engine_kit/`: exported geometry and conversion/provenance manifests.
- `source_library_manifest.json`: local Apex library inventory and source hashes.

The native hook retains its original 512px textures; the first-person grapple component has 1024px textures. Retriever body textures are 1024x512 with
512px blade textures. No upscaling is claimed. The axe HUD image now depicts
the recovered original Hell's Retriever; the old stock axe is only a reference.
The cable preview uses native dimensions and a 64-unit camera height; it is
an art reference, not proof of first-person alignment or game behavior.
