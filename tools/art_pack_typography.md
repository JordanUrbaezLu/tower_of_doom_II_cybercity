## TYPOGRAPHY — every letter, number and symbol uses OUR typeface

This game has its own typeface, and it is in this zip under `typography/`:

- `typography/i_tod_hud_letters.png` — the alphabet sheet: A-Z, `-`, `'`, the points coin, `.`
  (15 x 2 grid of 80 x 112 cells, reading order left-to-right then top-to-bottom)
- `typography/i_tod_hud_digits.png` — the numeral sheet: `0`-`9`, `/`, `+`, `-`
  (13 x 1 row of 128 x 160 cells)
- `typography/specimen.png` — the face set as real lines, so you can see how it spaces
- `typography/README.md` — the character list

This is the typeface's **2026-09-29 legibility revision**: a lighter stroke, a softer 3D edge,
slightly rounder corners and a curved S that can no longer be mistaken for a 5. Use the sheets in
THIS zip exactly as they are; any older copy of the face you may have is retired.

**Rules — these apply to every file you deliver:**

1. **Any text, number or symbol drawn on an asset is set in THIS typeface.** Titles, labels,
   names, tier numbers, prices, counts — all of it. Build words from the glyphs on the sheets
   (scaling them is fine). Do not use any other font, and do not draw your own lettering.
2. **Only these characters exist:** `A-Z`, `0-9`, space, `-`, `'`, `.`, `/`, `+`, and the
   points coin (which stands for money / points). **Uppercase only.** There is no lowercase,
   no `&`, `!`, `?`, `:`, `,`, `%` or `#`. If the brief's text seems to need one, rewrite the
   words so it does not (write `AND` for `&`), or ask.
3. **Keep the letterforms.** You may change the glyphs' FILL colour, add glow, or place them
   on a coloured plate to match the design — but not their shapes, outline or proportions.
   Mixed letters and numbers (`R-99`, `SPAS-12`) sit on one baseline at one height.
4. **Legible at the on-screen size.** Check every word shrunk to the size the brief gives.
