# Tower materials and lighting — first pass

Follow-up: [the broken descent](BROKEN_TOWER.md) now changes selected main-tower
stairs and doors. Geometry-preservation statements below describe this original
material/light pass; the current source audit reports the combined map.

2026-09-27. Combined FULL build passed; user playtest pending.
[Build evidence](BUILD_RESULT.md) · [Review](review.html). Counts below describe
the original lighting-only snapshot; the receipt records the current shared map.

The rest of the map now shares the crown's authored tread, service-panel, trim
and armor textures. Existing district colors remain recognizable, with 11 new
material tint roles using the existing 30 baked maps. This converts 53,394 faces;
the crown's existing assignments remain intact. Materials emit no light of their
own, retaining the dark-before-power design. Geometry and gameplay anchors have
not moved.

There are two new neutral light pools per lap: 100 on the main tower and 140 on
the spire. Each sits 120 units above its stair flight's midpoint. Landing lights
retain their district color. Base, underground rooms, wings, lounges, spire hubs
and summit lights receive a brighter, less saturated fill. This is a first light
placement pass; it does not add a new modeled fixture set or retune the crown's
alarm. Existing power behavior controls all the new lights.

All retuned/new lights use culling cutoff/falloff 20/60. These are initial values
for this map, not native-verified results. Reference: docs/162_lighting/01_lights.md.
The audit finds 582 total lights, 293 retuned lights, and zero new light origins
inside architectural solids. Actual light overlap, bleed and performance need
the bake and game test; origin clearance alone does not establish those.

The sky uses the same v6 city render and saturation 1.2. Its target score is
0.64 instead of 0.32, doubling image intensity. The visible-sky multiplier is
already at its documented maximum 10. Lowering skyStops from 1.85 to 0.85 holds
the calculated sky illumination steady: score times 2^skyStops is unchanged.
Exposure, fog and sun settings remain as before. Reference: chapter 05 of the
lighting guide. Final screen brightness still depends on BO3's tone mapping.

Reproduce the sky finishing in Blender 4.2 with tools/sky3d/finish_sky.py:

```text
--in %TEMP%/tod_sky3d/raw_8192_v6.exr --target-score 0.64
--white 1 --knee-w 0.7 --knee-max-w 1 --sat 1.2 --display-mult 10 --tag sky3d
```
